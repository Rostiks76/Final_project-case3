# Викторина

Веб-приложение для проведения интерактивных тестов с подсчетом баллов и таблицей лидеров.

## Технологии

- Python 3.8+
- Flask
- SQLite
- HTML/CSS

## Установка и запуск

1. Установите Flask:

pip install flask


2. Скачайте все файлы проекта в одну папку

3. Запустите приложение:

app.py

4. Откройте в браузере:

http://127.0.0.1:5000

## База данных

Используется SQLite. База данных создается автоматически при первом запуске.

## Функционал

- Случайный порядок вопросов
- Подсчет правильных ответов
- Вывод процента успеха
- Сохранение результатов
- Таблица лидеров (топ-10)
